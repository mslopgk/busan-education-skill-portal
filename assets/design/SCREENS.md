# 전개용 화면 사양 — 선택된 디자인 문법으로 9종을 찍어낸다

A안 메인은 시안 12종으로 이미 존재한다(`d01`~`d12`). 작성자가 하나를 고르면 그 문법을 아래 9종에
동일하게 적용한다. **내용은 제안서 본문과 어긋나면 안 된다** — 아래 수치·문구가 곧 검증 기준이다.

공통 규칙
- 모든 UI 텍스트 한국어. 연도는 2026년만. 부서명은 `부산광역시교육청 디지털미래교육과`.
- 금지: 이모지 아이콘, 영문 lorem, 2024·2025 날짜, 보라 그라디언트, Inter/Roboto/Arial/Space Grotesk.
- 색만으로 상태를 구분하지 않는다 — 배지는 색 + 텍스트를 함께.
- 렌더: `python tools/render_design.py <name> <height_css>` (1280 CSS px @2배 → 2560px).

안별 성격 (섞이면 안 되는 경계)
| | A안 | B안 | C안 |
|---|---|---|---|
| 명칭 | 교육용 AI 스킬 **아카이브** | AI 스킬 **포털** | AI 스킬 **포털** |
| 로그인 | **없음** | 있음(열람·다운로드는 비로그인 개방) | 있음(3단계 권한) |

1. `tools/render_design.py` 로 렌더 → `assets/stitch/` 로 복사(파일명은 기존 매핑 유지).
2. `python tools/build_ops.py` — `FIGURE_SWAP` 이 기존 `[그림 6·7·8]`(통합비교본은 3·5·7)을 교체한다.
3. `python tools/preview.py <보강.docx>` 로 Word 출력 검증.
4. 세로 비율이 1.4 를 넘으면 지면에서 폭이 깎인다 — 하단 공지·푸터를 잘라 `*-crop` 을 만들어 쓴다.
